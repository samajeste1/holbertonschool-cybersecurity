# The Quiet Engagement

Vanguard Security engagement VGD-LUM-2026-042 for Lumen Industrial Systems.

| File | PTES phase |
| --- | --- |
| `1-rules_of_engagement.md` | Pre-engagement. Scope, window, tools, stop rules. |
| `2-threat_model.md` | Threat model. Twelve threats on Lumen-controlled assets only. |
| `3-actions_log.md` | Vulnerability analysis, exploitation, post-exploitation. |
| `4-report.md` | Final report for the NIS2 conformity packet. |

Customer gateways and shop-floor sensors are out of scope. Reachability is not authorization. Metasploit is not used for the initial foothold.
